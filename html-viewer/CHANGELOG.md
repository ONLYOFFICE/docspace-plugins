# Change Log

## 1.0.0

### Added

- Initial version.
- `.html` and `.htm` files open in the ONLYOFFICE Apps viewer, rendered in an isolated frame. **Preview HTML** in the context menu opens the same viewer.
- Desktop, tablet and mobile preview widths, the last two in a device frame.
- On phones and tablets the viewer fills the screen, with a close button and arrows to the previous and next file.
- The source view, with syntax highlighting, line numbers and copying the HTML to the clipboard.
- Remote images are blocked until the reader chooses to load them.
- The interface and the description in all languages ONLYOFFICE Apps supports.
