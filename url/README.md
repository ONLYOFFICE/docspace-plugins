## Overview

Url files.

## How to configure

To start working with the plugin, it is not needed to change the default settings.

In case you want to adjust the plugin settings, go to *Settings -> Integration -> Plugins* and click on the gear symbol next to the ImageEditor plugin.

## How to use

The plugin is available via the *Actions* section in the file context menu of URL files.
